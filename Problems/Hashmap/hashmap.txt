
# 📘 HashMap Definition

**HashMap** is a data structure that stores data in **Key → Value** pairs.

```text
HashMap = Key → Value
```

Python-la HashMap-na:

```text
Dictionary (dict)
```

Simple definition (Interview):

> **"A HashMap stores data as Key-Value pairs and provides fast insertion, lookup, update, and deletion, usually in O(1) average time."**

**Interview keywords:**

```text
Key → Value

Fast Lookup

Fast Insert

Fast Update

Fast Delete

Average Time : O(1)
```
