
# 📘 CHAPTER 2 — TWO POINTERS

## 🧭 First: Two Pointers na enna?

Simple-ah sonna:

> **Oru array/string-la rendu positions-ai simultaneously maintain panni, avanga movement-ai control panni problem solve panradhu dhaan Two Pointers.**

Usually:

```text id="9g8g4q"
left  →                ←  right

[ 1 ][ 2 ][ 3 ][ 4 ][ 5 ][ 6 ]
  ↑                         ↑
 left                      right
```

Rendu pointers:

```text id="m2i6o5"
left
right
```

Condition based on:

```text id="9d8h4m"
left → move
right → move
both → move
```

---

# 🤔 Why Two Pointers?

Suppose:

```text id="w8z1c6"
nums = [1,2,3,4,5]
```

Question:

> Find two numbers whose sum is `6`.

Brute force:

```text id="uwj7z1"
1 + 2
1 + 3
1 + 4
1 + 5
2 + 3
...
```

Many unnecessary comparisons.

If array is **sorted**, we can do:

```text id="xk6z8p"
[1, 2, 3, 4, 5]
 ↑           ↑
left        right
```

Calculate:

```text id="7qv9t4"
1 + 5 = 6
```

Found! 🎯

Only two pointers needed.

---

# 🧠 Core Two Pointer Logic

For sorted array:

```text id="u6y1m8"
left = 0
right = len(nums) - 1
```

Then:

```text id="x3x8m9"
sum < target
    ↓
left += 1

sum > target
    ↓
right -= 1

sum == target
    ↓
Answer
```

Why?

Because array sorted.

Example:

```text id="4y7n5w"
[1,2,3,4,5]
 ↑       ↑
1       5

1 + 5 = 6
```

If:

```text id="v3z2kb"
1 + 5 = 7
```

Too big.

`right` move:

```text id="3b8d6v"
[1,2,3,4,5]
 ↑     ↑
left  right

1 + 4 = 5
```

Too small.

`left` move:

```text id="d4u7hs"
[1,2,3,4,5]
   ↑   ↑
 left right

2 + 4 = 6
```

Found.

# 🧠 TEMPLATE 1 — Opposite Pointers

```python
left = 0
right = len(arr) - 1

while left < right:

    # process arr[left], arr[right]

    if condition:
        left += 1

    else:
        right -= 1
```

Used for:

```text
Palindrome
Two Sum II
Container With Most Water
```

---

# 🧠 TEMPLATE 2 — Slow + Fast

```python
slow = 0

for fast in range(len(arr)):

    if condition:

        arr[slow] = arr[fast]
        slow += 1
```

Used for:

```text
Remove Duplicates
Move Zeroes
Remove Element
```

---

# 🧠 TEMPLATE 3 — Sort + Two Pointers

```python
nums.sort()

for i in range(len(nums)):

    left = i + 1
    right = len(nums) - 1

    while left < right:

        total = nums[i] + nums[left] + nums[right]

        if total == target:
            # found

        elif total < target:
            left += 1

        else:
            right -= 1
```

🔥 This becomes the foundation for **3Sum**.

# ⚠️ One Important Difference

**Two Pointers ≠ Sliding Window.**

They sometimes look similar because both use:

```text
left
right
```

But their purpose differs.

### Two Pointers

Usually:

```text id="p8q2m5"
left/right positions
        ↓
Compare / choose / partition
```

### Sliding Window

```text id="k4x7n1"
left/right
    ↓
Maintain a continuous window
    ↓
Condition
    ↓
Expand / Shrink
```

For example:

```text
Palindrome
→ Two Pointers
```

but:

```text
Longest substring without duplicate
→ Sliding Window
```

🔥 **Pointers same. Purpose different.**
