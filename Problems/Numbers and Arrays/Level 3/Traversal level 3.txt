# CHAPTER 1.3 – Traversal Pattern (Level 3)

## 1. Second Largest Element

### Concept

Find the **second biggest** element in the array.

### Recognition Keywords

* Second Largest
* Runner Up
* Second Maximum

### Core Idea

Maximum mattum store panninaa podhathu.

**Two variables maintain pannanum.**

```
largest

second_largest
```

Whenever a new maximum is found,

Old maximum becomes

↓

Second maximum.

### Python Template

```python
def second_largest(arr):

    largest = float('-inf')
    second = float('-inf')

    for num in arr:

        if num > largest:

            second = largest
            largest = num

        elif num > second and num != largest:

            second = num

    return second
```

### Pattern Formula

Traversal

↓

Compare Maximum

↓

Update Largest

↓

Update Second Largest

### Python Template

```python
def maximum_difference(arr):
```

## 4. Find Missing Number (Simple)

### Concept

Numbers from

```
1 to N
```

One number is missing.

Find it.

### Recognition Keywords

* Missing
* Missing Number

### Python Template

```python
def missing_number(arr, n):

    expected = n * (n + 1) // 2

    actual = sum(arr)

    return expected - actual
```

### Pattern Formula

Expected Sum

↓

Actual Sum

↓

Subtract

## 5. Remove Duplicates (Basic)

### Concept

Keep only unique elements.

### Recognition Keywords

* Duplicate
* Unique
* Remove

### Python Template

```python
def remove_duplicates(arr):

    result = []

    for num in arr:

        if num not in result:

            result.append(num)

    return result
```

## 6. Maximum Consecutive Ones

### Concept

Find the longest sequence of continuous

```
1 1 1 1
```

### Recognition Keywords

* Consecutive
* Continuous
* Maximum Ones

### Python Template

```python
def max_consecutive_ones(arr):

    count = 0
    maximum = 0

    for num in arr:

        if num == 1:

            count += 1
            maximum = max(maximum, count)

        else:

            count = 0

    return maximum
```

### Pattern Formula

Traversal

↓

Condition

↓

Increase Count

↓

Reset Count

↓

Update Maximum

## 7. Majority Element (Brute Force)

### Concept

Find the element appearing more than

```
n/2
```

times.

### Recognition Keywords

* Majority
* Most Frequent

### Python Template

```python
def majority_element(arr):

    for num in arr:

        count = 0

        for value in arr:

            if value == num:

                count += 1

        if count > len(arr) // 2:

            return num
```

### Note

Nested Loop

↓

O(n²)

Later

HashMap

↓

O(n)

## 9. Find Pivot Index (Basic)

### Concept

Find index where

```
Left Sum

=

Right Sum
```

### Recognition Keywords

* Pivot
* Left Sum
* Right Sum

### Beginner Template

```python
def pivot_index(arr):

    for i in range(len(arr)):

        left = sum(arr[:i])

        right = sum(arr[i+1:])

        if left == right:

            return i

    return -1
```

### Note

Current Complexity

```
O(n²)
```

Later

Prefix Sum

↓

O(n)

## 10. Best Time to Buy and Sell Stock (Traversal)

### Concept

Buy once.

Sell once.

Maximum Profit.

### Recognition Keywords

* Profit
* Buy
* Sell
* Stock

### Python Template

```python
def max_profit(prices):

    minimum = float('inf')

    profit = 0

    for price in prices:

        minimum = min(minimum, price)

        profit = max(profit, price - minimum)

    return profit
```

### Pattern Formula

Traversal

↓

Track Minimum Price

↓

Calculate Profit

↓

Update Maximum Profit
