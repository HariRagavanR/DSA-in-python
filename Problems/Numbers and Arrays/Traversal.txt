📘 CHAPTER 1 – TRAVERSAL PATTERN

---

# Pattern Name

**Traversal Pattern**

---

# Definition

Traversal means

> **Visit every element exactly once and process it.**

---

# Purpose

Traversal is used when we need to check every element in an array.

# Pattern Algorithm

```text
Start

↓

Visit first element

↓

Process it

↓

Visit next element

↓

Process it

↓

Repeat until last element

↓

Return answer
```

# Python Template 1

### Traverse using element

```python
for num in arr:
    # Process num
```

### Explanation

```text
num

↓

Current element

↓

Moves automatically
through every element
```

Example

```python
arr = [5,8,2,9]

for num in arr:
    print(num)
```

Output

```text
5
8
2
9
```

Use When

* Sum
* Count
* Maximum
* Minimum
* Average

---

# Python Template 2

### Traverse using index

```python
for i in range(len(arr)):
    # Process arr[i]
```

Explanation

```text
i

↓

Index

↓

0

1

2

3

...
```

Example

```python
arr=[10,20,30]

for i in range(len(arr)):
    print(i, arr[i])
```

Output

```text
0 10

1 20

2 30
```

Use When

Need index.

Example

* Find index
* Replace values
* Update array

# Template 3

### Maximum Element

```python
maximum = arr[0]

for num in arr:

    if num > maximum:

        maximum = num

return maximum
```

Algorithm

```text
Take first element as maximum

↓

Compare with every element

↓

If larger

↓

Update

↓

Return maximum
```

Time Complexity

```text
O(n)
```

Space

```text
O(1)
```

# Template 10

### Move Zeroes (Basic Traversal Logic)

```python
result = []

for num in arr:

    if num != 0:

        result.append(num)

while len(result) < len(arr):

    result.append(0)
```

# Common Mistakes

❌ Using nested loops for simple traversal

```python
for i in arr:
    for j in arr:
```

Time

```text
O(n²)
```

Usually unnecessary.

---

❌ Forgetting initialization

Wrong

```python
maximum = 0
```

Correct

```python
maximum = arr[0]
```

---

❌ Returning inside the loop without reason

Wrong

```python
for num in arr:
    return num
```

This returns only the first element.

## 💡 One small improvement to our notes

Instead of simply writing "Easy" and "Medium", let's split them into **Core**, **Pattern Building**, and **Interview Level**.

For Traversal:

* **Core (Must Master):** Print Array, Sum, Max, Min, Count Even/Odd, Linear Search.
* **Pattern Building:** First/Last Occurrence, Move Zeroes, Second Largest, Count Positives/Negatives.
* **Interview Level:** Best Time to Buy and Sell Stock, Pivot Index, Majority Element, Product of Array Except Self.

This way, you'll know exactly **which problems build the pattern** and **which ones test whether you've mastered it**. That's much more useful than difficulty labels alone. 🔥
